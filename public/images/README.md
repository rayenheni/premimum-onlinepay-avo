# Template image assets

These neutral, AI-generated template visuals are included only as starting assets for this project:

- `office-tunisia.jpg` — homepage and internal-page cover
- `justice.png` — services/journey visual
- `article-family.jpg`, `article-contracts.jpg`, `article-business.jpg` — journal defaults
- `video-poster.jpg` — optional intro-video poster

Before publishing a client site, replace assets with the client’s own imagery or visuals that they are licensed to use. Keep image filenames or update the corresponding settings in **Admin → Logo & apparence** and articles in **Admin → Articles**.
